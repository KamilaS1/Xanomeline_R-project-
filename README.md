# Анализ данных клинического исследования Xanomeline

Командный проект по курсу «Автоматизация обработки данных». В проекте на языке R выполнены импорт, очистка, объединение и описательный анализ данных клинического исследования препарата Xanomeline (две дозы препарата и группа плацебо). Итоговый отчёт собирается с помощью Quarto в один HTML-файл.

## Вариант 4

- **Группы лечения:** Placebo и Xanomeline Low Dose (170 участников: 86 и 84 соответственно). Группа Xanomeline High Dose и участники, не прошедшие скрининг, в анализ не включаются.
- **Лабораторные показатели:** гемоглобин (HGB, ммоль/л) и тромбоциты (PLAT, ×10⁹/л) на визите SCREENING 1.
- **Витальные показатели:** рост и вес на визите SCREENING 1, вес на визите WEEK 4; по ним рассчитывается индекс массы тела (ИМТ).
- **Генотип APOE:** определяется по вариантам rs429358 и rs7412; дополнительно рассчитываются носительство аллеля ε4 и число аллелей ε4 (0, 1 или 2).

## Содержание отчёта

1. **Импорт и очистка данных.** Отбор нужных столбцов, проверка уникальности участников, фильтрация по группам варианта и перевод данных из длинного формата в широкий (одна строка на участника). Результат: датафреймы `dm`, `lb_wide`, `vs_wide`, `gf_wide`.
2. **Объединение данных.** Присоединение всех таблиц к `dm` по столбцу `ID`, проверка числа строк и отсутствия дубликатов, подсчёт пропущенных значений по каждому столбцу.
3. **Описательные статистики.** Таблицы `flextable` с числом непустых и пропущенных значений, средним (СО), медианой [Q1; Q3] и минимумом–максимумом:
   - лабораторные показатели по группам лечения и по носительству ε4 (3.1);
   - ИМТ как количественный показатель и как категория «норма / не норма» по группам лечения и по числу аллелей ε4 (3.2);
   - распределение генотипов APOE по группам и статистики ИМТ и лабораторных показателей по генотипу (3.3).
4. **Дополнительные задания.** Графики `ggplot2` к таблицам раздела 3 (4.1) и воспроизведение таблиц с помощью `gtsummary::tbl_summary()` (4.2). Заполнение пропущенных значений средним по полу и возрастной группе (4.3) выполнено в отдельной экспериментальной ветке `imputation`.

## Как запустить

**Требования:**

- [R];
- [Quarto];
- среда разработки: Positron 

**Установка пакетов** (один раз, в консоли R):

```r
install.packages(c("tidyverse", "flextable", "gtsummary"))
```

**Сборка отчёта.** Клонируйте репозиторий и выполните в его корневой папке:

```bash
git clone https://github.com/KamilaS1/Xanomeline_R-project-.git
cd Xanomeline_R-project-
quarto render homework.qmd
```

## Работа с ветками

- `main` — основная ветка с итоговым отчётом.
- Каждый участник выполнял свой раздел (1.2–1.4, 3.1–3.3, 4.2) в отдельной ветке, после чего координатор сливал изменения в `main`.
- `imputation` — экспериментальная ветка, в которой перед разделом 3 пропущенные количественные показатели заполнены средним значением в группе по полу и возрасту (50–59, 60–69, 70–79, 80–89 лет).
